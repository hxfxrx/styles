# Core vocabulary for A2 Dutch

The thematic lists in each module add up to roughly 500 words. This file adds the high-
frequency "glue" words that don't fit a theme but appear in nearly every sentence. Together
(≈700 words) they cover the bulk of everyday A2 Dutch.

**How to study:** add each module's lists to your flashcard app as you reach that module; add
the lists below in weeks 1–4. Always learn nouns **with their article** (*de tafel*, not
*tafel*).
